# Dashboard_Customer_Churn_Analysis_PowerBI_SQL
Customer Churn Analysis using SQL and Power BI DirectQuery to identify customer behavior, analyze churn patterns, evaluate retention rates, and generate actionable business insights to improve customer retention and reduce customer attrition.

An interactive **Power BI dashboard** built using **SQL and DirectQuery** to analyze **7,043 customer records** and generate meaningful business insights through data visualization and reporting.

## 📌 Project Overview

This project focuses on analyzing customer churn data to understand customer retention, revenue performance, contract preferences, payment methods, customer behaviour, and service usage patterns.

The dashboard transforms customer data into actionable insights to identify churn patterns and support better customer retention strategies.

## 📊 Key Insights

- **Total Customers:** 7,043
- **Churn Rate:** 26.54%
- **Retention Rate:** 73.46%
- **Monthly Revenue:** ₹456.12K
- **Average Monthly Charges:** 64.76
- **Average Customer Tenure:** 32.37 months
- Month-to-month contracts accounted for the highest share of churned customers at 42.71%.
- Electronic check users showed the highest churn rate at 45.29%.
- Senior citizens had a higher churn rate of 41.68% compared to 23.61% for non-senior citizens.
- Customers within their first 12 months showed the highest churn concentration.
